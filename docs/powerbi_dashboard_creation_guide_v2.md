## 📊 데이터 구조 분석

### **핵심 테이블 구조**

#### **bi_scores_daily** - AI 스코어링 결과 (핵심!)

- `run_date`: 스코어링 실행일
- `account_id`: 고객 ID (Foreign Key - 57개 고유값)
- `t0_date`: 기준일
- `p_win_90d`: 90일 내 성사 확률 (0-1)
- `expected_amount_180d`: 180일 내 예상 거래금액
- `expected_value`: 기대가치 (확률 × 마진 - 접촉비용)
- `is_priority`: 우선순위 여부 (0/1)

#### **accounts** - 고객 기관 정보 (중복 제거 완료!)

- `account_id`: 고객 ID (Primary Key - 57개 고유값)
- `account_name`: 기관명 (예: 기관_001)
- `account_type`: 기관 유형 (검사실, 의원, 병원)
- `bed_count`: 병상 수
- `annual_test_volume`: 연간 검사량
- `city`, `state_region`, `country`: 지역 정보
- `ownership_type`: 소유 형태 (민영, 공공)
- `created_at`, `updated_at`: 생성/수정일
- `기관규모`: 대형/중형/소형 (파이썬에서 생성)

#### **기타 테이블들**

- **opportunities**: 43행 (영업 기회)
- **orders**: 46행 (주문 정보)
- **interactions**: 122행 (고객 상호작용)
- **products**: 243행 (제품 정보)

2. **모델 뷰**로 전환됨

#### **관계 설정 (자동 감지됨)**

Power BI가 자동으로 다음 관계를 감지할 것입니다:

- `accounts[account_id]` → `bi_scores_daily[account_id]` (1:1)
- `accounts[account_id]` → `opportunities[account_id]` (1:*)
- `accounts[account_id]` → `orders[account_id]` (1:*)
- `accounts[account_id]` → `interactions[account_id]` (1:*)

#### **날짜 테이블 생성**

```dax
DimDate = 
GENERATE(
    CALENDAR(DATE(2023,1,1), DATE(2025,12,31)),
    VAR CurrentDate = [Date]
    RETURN ROW(
        "Year", YEAR(CurrentDate),
        "Month", MONTH(CurrentDate),
        "MonthName", FORMAT(CurrentDate, "YYYY-MM"),
        "Quarter", "Q" & FORMAT(ROUNDUP(MONTH(CurrentDate)/3,0), "#"),
        "Weekday", FORMAT(CurrentDate, "dddd"),
        "WeekdayNumber", WEEKDAY(CurrentDate,2)
    )
)
```

#### **날짜 테이블 관계 설정**

1. **모델 뷰**에서 **DimDate[Date]**를 다음 필드들과 연결:
   - `orders[order_date]`
   - `interactions[occurred_at]`
   - `opportunities[created_at]`
   - **⚠️ 주의**: `bi_scores_daily[t0_date]`는 연결하지 않음 (모든 레코드가 동일한 날짜이므로)

## 📊 2단계: DAX 측정값 생성

### 2.1 리드 스코어링 KPI 측정값

#### **총 고객 수 측정값 생성**

```dax
총고객수 = DISTINCTCOUNT(accounts[account_id])
```

#### **우선순위 고객 수 측정값 생성**

```dax
우선순위고객수 = 
CALCULATE(
    DISTINCTCOUNT(accounts[account_id]), 
    bi_scores_daily[is_priority] = 1
)
```

#### **평균 스코어 측정값 생성**

```dax
평균스코어 = AVERAGE(bi_scores_daily[p_win_90d])
```

#### **총 예상 매출 측정값 생성**

```dax
총예상매출 = SUM(bi_scores_daily[expected_amount_180d])
```

#### **실제 매출 측정값 생성**

```dax
실제매출 = SUM(orders[total_amount])
```

#### **우선순위 고객 비율 측정값 생성**

```dax
우선순위고객비율 = 
DIVIDE([우선순위고객수], [총고객수], 0)
```

#### **스코어 등급별 측정값들**

```dax
A등급고객수 = 
CALCULATE(
    DISTINCTCOUNT(accounts[account_id]),
    bi_scores_daily[p_win_90d] >= 0.7
)

B등급고객수 = 
CALCULATE(
    DISTINCTCOUNT(accounts[account_id]),
    bi_scores_daily[p_win_90d] >= 0.4,
    bi_scores_daily[p_win_90d] < 0.7
)

C등급고객수 = 
CALCULATE(
    DISTINCTCOUNT(accounts[account_id]),
    bi_scores_daily[p_win_90d] < 0.4
)
```

### 2.2 영업 퍼널 측정값

#### **총 기회 수 측정값 생성**

```dax
총기회수 = DISTINCTCOUNT(opportunities[opportunity_id])
```

#### **활성 기회 수 측정값 생성**

```dax
활성기회수 = 
CALCULATE(
    DISTINCTCOUNT(opportunities[opportunity_id]),
    opportunities[stage] <> "ClosedWon",
    opportunities[stage] <> "ClosedLost"
)
```

#### **단계별 기회 수 측정값들**

```dax
MQL기회수 = 
CALCULATE(
    DISTINCTCOUNT(opportunities[opportunity_id]),
    opportunities[stage] = "MQL"
)

SQL기회수 = 
CALCULATE(
    DISTINCTCOUNT(opportunities[opportunity_id]),
    opportunities[stage] = "SQL"
)

POC기회수 = 
CALCULATE(
    DISTINCTCOUNT(opportunities[opportunity_id]),
    opportunities[stage] = "POC"
)

ClosedWon기회수 = 
CALCULATE(
    DISTINCTCOUNT(opportunities[opportunity_id]),
    opportunities[stage] = "ClosedWon"
)
```

#### **전환율 측정값 생성**

```dax
전환율 = 
DIVIDE([ClosedWon기회수], [MQL기회수], 0)
```

### 2.3 상호작용 분석 측정값

#### **총 상호작용 수 측정값 생성**

```dax
총상호작용수 = COUNTROWS(interactions)
```

#### **채널별 상호작용 수 측정값들**

```dax
데모상호작용수 = 
CALCULATE(
    COUNTROWS(interactions),
    interactions[channel] = "demo"
)

이메일상호작용수 = 
CALCULATE(
    COUNTROWS(interactions),
    interactions[channel] = "email"
)

방문상호작용수 = 
CALCULATE(
    COUNTROWS(interactions),
    interactions[channel] = "visit"
)

전화상호작용수 = 
CALCULATE(
    COUNTROWS(interactions),
    interactions[channel] = "call"
)
```

#### **성공적 상호작용 비율 측정값 생성**

```dax
성공적상호작용비율 = 
DIVIDE(
    CALCULATE(COUNTROWS(interactions), interactions[outcome] = "positive"),
    [총상호작용수],
    0
)
```

## 🎨 3단계: 시각화 구성

### 3.1 페이지 1: 리드 스코어링 대시보드 생성

#### **주제**

AI 기반 리드 스코어링을 통한 고가치 고객 식별 및 우선순위 관리

#### **🎯 이 페이지에서 주장하려는 내용**

**"AI가 식별한 우선순위 고객에게 집중하면 영업 효율성을 극대화할 수 있다"**

- **핵심 주장**: 57명의 고객 중 AI가 선별한 우선순위 고객(50% 이상 성사 확률)에게 집중 투자하면 ROI를 최적화할 수 있음
- **데이터 근거**: 
  - 우선순위 고객의 평균 성사 확률과 예상 매출이 일반 고객 대비 현저히 높음
  - 지역별, 기관 유형별로 스코어 분포가 다르므로 세분화된 접근 전략 필요
  - 기대가치(ROI) 기반으로 투자 우선순위를 명확히 제시

#### **페이지 생성 및 제목 설정**

3. **대시보드 이름**: "IVD Lead Scoring Dashboard"

#### **시각화 요소 고정**

1. **보고서** → **리드 스코어링 대시보드** 선택
2. **각 시각화 요소**에 마우스 오버
3. **고정** 아이콘 클릭 → **대시보드** 선택
4. **다른 페이지들**도 동일하게 고정

### 7.3 공유 설정

#### **사용자 공유**

1. **대시보드** → **공유** → **사용자에게 공유** 클릭
2. **이메일 주소** 입력
3. **권한**: 보기 또는 편집
4. **메시지** 입력 후 **공유** 클릭

#### **링크 공유**

1. **공유** → **링크 생성** 클릭
2. **링크 설정**:
   - **액세스 권한**: 조직 내 사용자
   - **만료일**: 설정 (선택사항)
3. **링크 복사** 후 공유
